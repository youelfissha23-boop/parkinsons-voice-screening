# Parkinson's Voice Screening (v1 in progress)

Machine-learning experiments on a small public dataset of voice recordings, exploring early Parkinson's screening with a focus on honest evaluation: splitting by person to avoid data leakage.

> Educational research project. Not a medical device and not for diagnosis.
